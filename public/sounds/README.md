# The music of BitPortal's room

Eight pieces, played in turn, each fading into the next. The owner chose
them by ear on 2026-11-18 from pieces made for BitPortal.

| Files | Made with |
|---|---|
| `room-a.ogg` to `room-d.ogg` | code: a synthesizer written for the purpose, with no model, sample or recording behind it |
| `room-e.ogg` to `room-h.ogg` | YuE2, a music model, run on the owner's own machine |

The first to play is `room-b`, the one the owner picked first. The two kinds
take turns.

**About YuE2.** The agent that made these files could not find a licence
file for YuE2 and reported its terms for redistributing output as unclear.
The owner settled it on 2026-11-18: "YuE2 is clear for us to use. Ship
them". That decision is theirs, and it is recorded here so that anyone who
takes these files knows what it rests on.

All eight are offered under this repository's licence, as far as that is the
owner's to give.

The cues and the room's hum are the NSWP kit's own, in `vendor/nswp/sounds/`,
whose README says where each of those came from.
